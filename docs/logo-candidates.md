## まとめ

- **今すぐ追加可能（simple-icons 収録）: 296 件**
- 別ソースが必要: 38 件
- 既存アプリ収録済み: 14 件（✅）

**この表が `catalog.json` の生成元です。** 上記の 296 行（重複 5 件を除いた 291 件）はすべて
`src/data/catalog.json` の `shapes`（`group: "Logo"`）に収録済みで、節の見出しがパレットの小分類になります。

ロゴを増減するときは、この表を編集してから再生成してください:

```bash
npm run build:logos          # docs/logo-candidates.md → src/data/catalog.json
npm run build:logos -- --dry # 書き込まずに差分だけ確認
```

生成スクリプトは `scripts/build-logos.mjs`。slug は `simple-icons` パッケージから解決し、
見つからない slug は警告として報告されます（表の 3 列目の色は simple-icons 側の値が優先）。
既存エントリの SVG とラベルは再生成しても維持されます。
